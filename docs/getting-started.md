# Getting Started with AEGIS BOT SHIELD

## Prerequisites
- Node.js (v16+) for JS SDKs.
- Python 3.8+ for Python SDKs.
- A valid AEGIS API Key.

## Installation

### Node.js / Express
```bash
npm install @aegis/shield
```

### Python / Flask
```bash
pip install aegis-shield
```

## Quick Start

### 1. Obtain an API Key
Sign up at our dashboard and generate a new API key.

### 2. Integrate into your application
Choose your preferred integration method from the examples directory.

### 3. Monitor
Log into the AEGIS dashboard to monitor traffic and block events in real-time.
